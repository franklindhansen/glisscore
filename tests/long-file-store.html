Disk store check

Reads a recording into the disk store the way the app will for long files, reads it back, and compares it with the way the app reads files today.

WAV, M4A or MP4. The comparison holds the whole recording in memory, so it turns itself off for files over 20 minutes. A file that is already in the store is used as it is, unless Read in again is on. Play runs straight from the disk: drag the slider to jump. With Play through the tools on, the sound is worked out as it plays (noise reduction, Spectra, EQ, Imager), and Change the EQ swaps between a bright and a muffled EQ without stopping. Delete frees the disk space.
