# Changelog

## 0.5.1

Long scanned PDFs use far less memory, so a 220-page scan no longer pushes the browser to reload the tab as easily. Page cards far from the view free their pictures and draw again as you scroll, the browser keeps fewer remembered page pictures, and the file is held once. The page-turn button now reads Add page turn, as in the shortcuts, and a greyed Revert no longer puts "Nothing to revert." on the tool's status line; it is a tooltip.

## 0.5.0

Wrap is gone, and with it the Turn style choice. A Single page turn is always Peel now: the page lifts and curls from its free edge and is carried off to the left. Videos and settings files saved with a turn style load without it.

## 0.4.0

Wrap now turns the page once around its left edge, like a notebook folded in half: it swings out, lingers fully open, then folds back behind the next page. A faint fold line keeps it attached, and its shadows follow what is happening.

## 0.3.1

The PDF Editor's loading cards now share one sweep across the grid, and the large view's page box and the crop frame glide more smoothly.

## 0.3.0

Wrap is a new turn style for Single page: the page folds over its left edge and lands behind the next one. It replaces Fade; videos saved with Fade load as Peel.

## 0.2.0

History in the video editor now records every output setting as a named step, including Restore defaults and importing settings.

## 0.1.0

First numbered release: the Audio Editor, PDF Editor and video editor, with a Single page layout and Turn, Slide and Peel page turns.
